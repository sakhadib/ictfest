# **অলীকবচন : Bengali LLM Hallucination Detection Challenge**
 

# **Competition Description**

This year's challenge is **অলীকবচন : Bengali LLM Hallucination Detection Challenge**. Participants will work on detecting hallucinated outputs from **Bengali Large Language Models (LLMs)**, encouraging innovative solutions for real-world language technology problems.

# **Eligibility Criteria**

* Teams can consist of up to 4 members.  
* Participant must be a currently enrolled undergraduate student from any recognized university in Bangladesh.  
* To verify student status, each participant must submit a valid student ID card during registration.  
* International teams are allowed, but at least one team member must be Bangladeshi.  
* Cross-university teams are allowed

# **Rules and Guidelines**

● Only one account per participant in Kaggle will be allowed.

teams.   
● It will be a 25 day long competition with multiple phases.  
● No private code sharing outside teams.

## **Models, Training and Compute Rules**

### 

### **Pretrained Models**

Publicly available **open-source pretrained models** are allowed, provided they are appropriately licensed.  
Participants must disclose:

* Model name and version with repository link  
* License information  
* Claimed pretraining data (as stated by the model authors)

### 

### **Fine-Tuning**

Fine-tuning of pretrained models is permitted.

### 

### **API Prohibition**

The use of **any external API** is strictly prohibited. This includes, but is not limited to, OpenAI, Claude, or any hosted services.  
All inference must be performed **locally within Kaggle notebooks**.

### 

### **External Infrastructure**

External infrastructure may be used for **training purposes only**.  
Final submissions must be **fully reproducible on Kaggle**.

### 

### **4.5 External Data Policy**

The use of external data is allowed under the following conditions:

* The data must be publicly available, curated from public sources, or created during the competition runtime.  
* All external data must be clearly declared and made public with proper citations.  
* External data must **not** include or be derived from any competition test set.

**Submission Requirements** 

Each team must submit:

* A **training notebook** (Preferred to be Kaggle-runnable) \- If applicable  
* An **inference notebook** (Must be Kaggle-runnable and capable of generating the final submission)  
* Participants must submit a script to run the code. Submissions will not be considered if  
  the script is not provided.  
* Model checkpoints or weights (preferably hosted on Hugging Face)  
* Clear documentation (README within the notebook or markdown cells)  
* A video presentation of a maximum of 7 minutes (Just Methodology) has to be submitted within the competition deadline  
* Participants need to submit a 4-page report following the IEEE paper format **I**  
* Teams are strongly encouraged to upload their paper to [**arXiv**](https://arxiv.org/)  or github and submit the corresponding link.

**Re-run Policy:**  
All submissions will be rerun on both the public and hidden test sets after Phase 1 concludes.  
The inference notebook must execute within Kaggle runtime limits (CPU or GPU, as permitted).

**Submission Limit:**  
Will be set when the competition launches.

● Submissions will be evaluated based on the following criteria:

1. Models accuracy and efficacy of data interpretation.  
2. Inference result.  
3. Video Presentation and comprehensive report.  
4. Functional script of the code

● Participants must refrain from any form of plagiarism or unethical practices. All work must be original, and proper credit must be given to external sources if used.

● Manually labelling inference data is strictly prohibited and will result in disqualification.

**NOTE: The authority has the prerogative to make conclusive decisions at any point during the entire competition duration.**  
**NOTE: Use of common sense is highly recommended. Idiotic and deliberate mistakes  like idea sharing  between teams or trying to submit anything  without joining teams won’t be tolerated .**
