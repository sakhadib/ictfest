ICT Fest Telegram Bot Commands

All commands work in the configured Telegram group through webhook updates.
Slash commands and plain text variants are supported where noted.

help
/help
commands
/commands
Shows the list of available commands.

status
/status
Shows the overall registration summary:
total registrations, total participants, today's registrations, today's participants, and counts grouped by event.

today
/today
Shows today's registrations and participant counts grouped by event.

events
/events
live
/live
Shows each event's live/taken-down status and slot availability where a slot limit exists.

pending
/pending
Shows pending registration review counts grouped by event.

payments
/payments
Shows submitted payment counts waiting for confirmation, grouped by event.

finals
/finals
Shows final registration pipeline counts grouped by event:
invited, submitted, approved, and rejected.

ca
/ca
Shows registration counts grouped by Campus Ambassador name.
Blank CA values are shown as Unassigned.

event <code>
/event <code>
Shows a focused summary for one event.
Examples:
event 01
/event 03

trend <code>
/trend <code>
Queues and sends a PNG line chart with cumulative registrations for one event.
Examples:
trend 02
/trend 05

trend all
/trend all
Queues and sends a PNG line chart with cumulative registration curves for all events.

univ
/univ
Queues and sends a PDF report of university-wise participant counts by event.
Columns: university, IUPC, Hackathon, Datathon, Gamejam, FIFA, Valorant, total.

fullreport
/fullreport
Queues and sends the complete registration PDF report in parts.
Includes event overview, status summaries, CA summary, university participant counts, daily trend tables, registrations, participants, coaches, payment records, and final registration records.

fullreport-force
/fullreport-force
Queues and tries to send the complete registration PDF report as one file.
If Telegram refuses the upload, the bot points admins to /fullreport and the dashboard PDF download.

regcard all
/regcard all
Queues and sends registration cards as one PDF per event.

regcard force
/regcard force
Queues and tries to send all registration cards in one PDF.

regcard event <code>
/regcard event <code>
Queues and sends registration cards for one event, excluding pending registrations.
Example: /regcard event 01

regcard event <code> all
/regcard event <code> all
Queues and sends registration cards for one event, including pending registrations.
Example: /regcard event 01 all

regcard team <registration-code>
/regcard team <registration-code>
Queues and sends a single team registration card.

tshirt event <code>
/tshirt event <code>
Queues and sends a CSV for paid T-shirt rows of one event.
Columns: registration code, team name, person, person type, participant institution, paid amount, T-shirt size.
Person type can be leader, participant, or coach.
